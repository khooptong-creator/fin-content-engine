# YouTube Project Roadmap (100-Day Sprint)

This roadmap outlines the path from 0 to 100 videos across both channels (Finance & Baby). 

## Phase 1: Foundation (Week 1)
- **Goal:** Set up channel architecture and the first batch of assets.
- **Tasks:**
  - Create YouTube accounts, verify phone numbers (for custom thumbnails), and set up channel art.
  - Setup Notion/Project Tracker for video statuses.
  - Generate the first 7 scripts for both channels using the AI Prompts.
  - Test animation workflows: generate 1 test video per channel to measure actual creation time.

## Phase 2: The Batching Engine (Weeks 2-4)
- **Goal:** Achieve the "1-a-Day" publishing cadence (14 videos a week total across 2 channels).
- **The Weekly System:**
  - **Sunday (2 Hours):** Ideation & Scripting. Run LLM prompts to generate 7 Finance scripts and 7 Baby scripts. Review and approve.
  - **Monday (1 Hour):** Voiceovers. Batch generate all 14 audio tracks using ElevenLabs.
  - **Tuesday - Thursday (4 Hours/day):** Animation & Editing. Combine VO with templated assets. 
  - **Friday (1 Hour):** Thumbnails & Scheduling. Use YouTube Studio to schedule 1 video per day for the following week.
  - **Saturday:** Rest / Review Analytics.

## Phase 3: Optimization & Feedback (Weeks 5-10)
- **Goal:** Analyze YouTube Studio retention graphs and adapt.
- **Metrics to track (KPIs):**
  - **Swipe-Away Rate (Shorts):** Aim for > 70% "Viewed" (vs Swiped Away). If lower, fix the 0:03 hook.
  - **Average Percentage Viewed (APV):** Aim for > 80% on a 60-second video. If it dips at a certain timestamp, review what happened visually.
- **Action:** If Finance viewers drop off during complex charts, simplify to analogies. If Baby viewers drop off, slow down the pacing even further.

## Phase 4: Monetization Prep (Weeks 11-14)
- **Goal:** Cross the 100-video mark and apply for YPP.
- **Finance Channel:** Launch the Beehiiv newsletter. Add a CTA to the link in bio on all new Shorts.
- **Baby Channel:** Consolidate the 100 short videos into 10-minute long-form compilations (e.g., "30 Minutes of Learning Colors!"). This explodes Watch Hours required for monetization.
- **Apply to YPP:** Once thresholds are met, activate AdSense.
