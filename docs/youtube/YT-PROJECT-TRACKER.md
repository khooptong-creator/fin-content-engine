# YouTube Project Tracker

*Use this structure in a Kanban board (Trello, Notion, or GitHub Projects).*

## Columns / States

1. **Idea / Backlog**
   - Just a title and a hook.
2. **Scripting**
   - Script is generated and awaits human review.
3. **Voiceover**
   - Script is approved, waiting for AI TTS generation.
4. **Animation / Editing**
   - Audio is locked. Visuals are being added.
5. **Thumbnail & Metadata**
   - Video exported. Needs title, tags, description, and thumbnail.
6. **Scheduled / Published**
   - Uploaded to YouTube Studio.
